* 彻底逆向原版的混淆代码以允许审计, 贡献, 扩展

* 维护频率会按照最低可用限度进行更新, 在我能力范围内提供不定期维护支持

代理核心支持：

* 默认使用 Mihomo 的 Core，
* 可在“设置 → 通用 → 代理核心”切换为 2023 Clash Core；切换后应用会自动重启代理核心以兼容旧的配置和使用习惯。
* Mihomo 模式支持 AnyTLS。内置配置编辑器可编辑常用 AnyTLS 字段，并在再次编辑时保留 ShadowTLS、ResTLS、JLS 等高级字段。
* 当前构建资源包含 Windows x64、Windows x86、Windows ARM64、Linux x64、Linux ARM64、macOS Intel 和 macOS Apple Silicon 的 Mihomo 核心。
